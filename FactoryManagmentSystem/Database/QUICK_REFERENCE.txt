WORKFLOW CHANGES:
-----------------

OLD WORKFLOW (WRONG):
  1. Owner Approves
  2. Production created
  3. Delivery created immediately ❌ (WRONG!)
  4. Tailors assigned
  5. Tailors work independently

NEW WORKFLOW (CORRECT):
  1. Owner Approves
  2. Production created + Tailors assigned
  3. One tailor starts → ALL tailors marked "InProgress"
  4. One tailor completes → ALL tailors marked "Complete"
  5. Delivery AUTOMATICALLY created ✅ (CORRECT!)
  6. Status changes to "ReadyForDelivery"


KEY FEATURES:
-------------
✅ SalesOrders and Deals both create deliveries
✅ Tailors work collaboratively (shared status)
✅ Delivery created ONLY after production completes
✅ UI displays both order types correctly
✅ Database supports mutually exclusive foreign keys
